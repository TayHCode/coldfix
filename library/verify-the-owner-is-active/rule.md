# Verify an owner is active before recommending that the user wait

Before recommending that a user wait or leave a task alone, verify that its owner or process is active and has a concrete next step. If it is idle, address the user's requested status or audit questions directly.

## How to check

Check the reported owner or process state and identify its next action before advising the user to wait.
