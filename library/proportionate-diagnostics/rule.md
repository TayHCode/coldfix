# Keep diagnostic requests proportionate

Choose the smallest diagnostic that can distinguish the likely causes. Avoid asking users to dump broad configuration or environment output when a focused check will answer the question.

## How to check

Before sending troubleshooting steps, check that each requested command is necessary to decide the next action and that a narrower check would not suffice.
