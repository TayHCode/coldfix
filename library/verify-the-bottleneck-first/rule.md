# Verify the bottleneck before prescribing an architecture

Before presenting a system diagnosis or architecture change as the solution, connect it to the user's stated bottleneck and identify the evidence supporting that connection. If the evidence is incomplete, label the diagnosis as a hypothesis.

## How to check

Read the recommendation message and check whether it identifies evidence for the user's stated bottleneck or clearly labels the diagnosis as a hypothesis.
