# Upgrade docs must back up the configured store as well as .hub-store

Backup instructions for a custom store_path must tell users to copy that folder in addition to .hub-store, not instead of it. Imported items and history remain in .hub-store, so both directories are needed for a complete backup. Recheck the upgrade doc wording before pushing docs changes.
