# Do not describe an unfinished check as a blocker when a documented fallback works

When a documented fallback works, use it for the requested check and report any remaining limitation precisely instead of calling the whole check blocked. Distinguish a failed setup route from a failed verification.

## How to check

Check whether the transcript shows a working documented fallback before the agent describes the task or check as blocked.
