# Exclude inline review bodies edited after merge from evidence

Inline review comments used as merge-time evidence must be filtered by their last edit time, not only their creation time. Apply the same post-merge cutoff already used for issue comments, or retain a pre-merge copy. Cover an inline comment edited after merge with a test.
