# Security

Coldfix stores captured commands and error text as plaintext files in a local store, and it can run an authored check
against two Git revisions when you explicitly ask it to replay. Treat the store as private, and review a check before
you replay it. Do not include tokens, private hostnames or personal paths in reports.

Report a vulnerability privately through GitHub's "Report a vulnerability" button on the repository's Security tab, if it
is enabled, rather than in a public issue. No support or response-time commitment is offered.
